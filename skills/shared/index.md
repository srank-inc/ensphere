# Shared Contracts

- [workflow-contract.md](workflow-contract.md) defines responsibilities,
  lifecycle, decisions, coverage, safety, and optional-session boundaries.
- [evidence-standards.md](evidence-standards.md) defines provenance, evidence
  strength, finding status, controlled validation, and reproducibility.

Read both before any session methodology. Category files may narrow them but
cannot weaken them.

Core separation:

- Ensphere records deterministic facts.
- The analyst assigns status, confidence, severity, priority, impact, and
  remediation.
- Human-authorized Session 10 outcomes are optional and separate from the base
  Session 09 finding status.
